## Production and rollback

The primary host is the existing Cloudflare Pages Direct Upload project `datacenter-twin-lab`, production branch `main`, at `https://khanlab.co.technology/`. GitHub Pages publishes only the existing forwarding artifact. A GitHub Release does not update the primary domain. After the verified merge and annotated tag, publish the reviewed GitHub assets and upload the exact tested static artifact to that existing project, with the merge SHA recorded as the deployment commit. Confirm anonymous served hashes, build identity and old/new routes before recording deployment success.

Source corrections use a reviewed revert or follow-up commit, never a retargeted release tag.
