# 2.0.1 — Numerical and packaging maintenance

This maintenance candidate makes fixes already present in later source available
in a separately versioned package. It adds no model, dependency, schema or
operational control. A prepared note or tag is not publication: use the actual
[published releases](https://github.com/mohammadrezwankhan/datacenter-twin-lab/releases)
for available packages and their exact source, checksum and completed checks.

## What changes from the original 2.0.0 wheel

- The forced-response spectrum correctly doubles the final positive-frequency
  coefficient for its 801-sample odd-length record. The saved 30 Hz / 0.05 pu
  input and scalar-DFT regression cover this teaching case. See the
  [equations and reproduction commands](../studies/power-dynamics.md#check-the-last-spectrum-bin).
- Native dashboard staging removes obsolete files. Wheel verification compares
  every current web path and SHA-256 byte hash before a fresh installation,
  including files outside the evidence manifest. Build from a fresh packaging
  tree; an old setuptools build cache is not release evidence.
- The Python quickstart includes short-path PowerShell setup. The existing
  API dependency maintenance and installed-package checks remain in scope.
- Current-version evidence auditing and source/archive links stay separate
  from the list of actually published packages.

The [new continuity packet](../../data/evidence/index-v2.0.1.json) changes engine
version and deterministic run identifiers. All other canonical run JSON fields,
scenario input hashes, equations and outcomes are checked against the original
2.0.0 packet. The 100/50 kWh charging-disabled examples retain 307.8/153.9 seconds
of ride-through. These continuity cases are separate from the corrected spectrum.

## Compatibility and evidence boundaries

Planning schema 1, electrical schema 2, infrastructure-screen-1, eighteen
facility presets and the 30-item Learn catalog remain. Unchanged infrastructure
content versions, source labels and Engineering HOLD remain. Recalculate old
inputs with the selected engine version; preserve old exports when comparing IDs.
The original v2.0.0 tag, wheel, evidence packet and publication decision remain
unchanged. Do not label the old wheel as the corrected package.

Release gates include fresh installed core/API/studies journeys, complete result
comparisons, 24 lesson defaults/challenges, browser/native/on-demand Python
equality, Windows/Linux 3.12/3.14 CI, and exact static hosting verification.
Only the external release receipt identifies the final tested revision and assets.
No PyPI publication, independent external reproduction, physical calibration,
hardware qualification, certified uptime or GPU-job prediction is established.
